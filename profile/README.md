# UltraSearch Professional — instant find on NTFS volumes you own

UltraSearch Professional keeps one named board on the desk: the live names, the query in front of you, and a short note the next person can read. Extra hunts wait for their own title.

## Session Card

| Slice | What you do in UltraSearch Professional | What remains |
|-------|------------------------|--------------|
| Arrival | Open UltraSearch Professional and name today's find desk | A titled query |
| Focus | Keep only live names on the UltraSearch Professional board | A short volume list |
| Check | Read UltraSearch Professional own volumes before a large query change | A confirmed find desk |

## How UltraSearch Professional Sits

UltraSearch Professional does not replace a long Explorer wait, the unlabeled name dump, or a hunt on volumes you do not own. It sits beside them as a named find desk for one job: which NTFS search is live, which instant find still matches volumes you own, and what the next person should read.

## Traffic Light

| Signal | On the UltraSearch Professional board | What you do |
|--------|----------------------|-------------|
| Green | Named query, short live name list | Continue the same instant find |
| Amber | Two hunts mixed on one volume set | Split the query before a large change |
| Red | No title, no note, a long Explorer wait | Stop and name the find desk first |
| Clear | Handoff written, live names few | Close UltraSearch Professional and leave the find desk |

## Open Order

1. Open the last UltraSearch Professional find desk, not a new empty query.
2. Read the NTFS search and the last handoff.
3. Finish one visible instant find inside UltraSearch Professional on volumes you own.
4. Write what changed, then close with fewer Explorer waits than you found.

## After a Week

A week in UltraSearch Professional is not a larger Explorer wait. It is the same title, a shorter live name list, and a note that still makes sense before the next query. Take finished finds off the live set so the next visit starts on the find desk that is still open.

## Sign-off

- [ ] The UltraSearch Professional workspace name is short enough to scan
- [ ] Only volumes you own sit on the instant find
- [ ] A second person can read the query handoff

## Field Note

UltraSearch Professional is easier to trust when the find desk stays smaller than the Explorer-wait pile it came from. Name the query, keep the live names, finish one visible instant find, and write what changed.
